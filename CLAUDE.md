# CLAUDE.md

## Permissions

- Never request permissions, access or app installations from any GitHub organization
  associated with the user's account (e.g. adding repositories, installing or reconfiguring
  GitHub Apps, asking an organization owner to grant access).
- Work only with the access the session already has. If a task needs a permission that is not
  available (for example, a push rejected by a protected branch), stop, explain what is missing
  and why, and propose an alternative that works with the current access.
